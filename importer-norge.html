Badekulpen — hent badeplasser fra hele Norge

Denne siden henter alle steder av typen Badeplass og Strand fra Kartverkets stedsnavnregister, og anslår om hvert sted ligger ved saltvann, innsjø eller elv ved å se på terrenget rundt det (Kartverkets høydedata). Det tar noen minutter. Du trenger ikke være logget inn.

Klar.
Når filen er lastet ned:
  1. Gå til Badekulpen-repoet på GitHub → Add file → Upload files.
  2. Dra inn badeplasser-norge.json og trykk Commit changes.
  3. Etter et par minutter vises stedene i kartet. Kjør denne siden på nytt når du vil ha med nye steder fra Kartverket.
